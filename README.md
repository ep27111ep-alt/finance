# Бюджет

Личный сервис учёта расходов: сколько можно тратить в день, лимиты по категориям, утечки, импорт банковских выписок (CSV/Excel), цели накоплений.

Страница работает на GitHub Pages, данные хранятся в Supabase. Каждый пользователь видит только свои данные.

## Файлы

- `index.html` — сам сервис
- `config.js` — адрес и ключ твоей базы Supabase (заполнить)
- `setup.sql` — создаёт таблицу и правила доступа (выполнить один раз)

## Настройка (один раз, ~15 минут)

### 1. База данных в Supabase
1. Зарегистрируйся на https://supabase.com (можно через GitHub) и нажми **New project**. Регион: Frankfurt или ближайший. Пароль базы сохрани, но для сервиса он не понадобится.
2. Когда проект создастся, открой **SQL Editor → New query**, вставь всё содержимое `setup.sql` и нажми **Run**. Должно появиться «Success».
3. Создай себе пользователя: **Authentication → Users → Add user → Create new user**. Впиши почту и пароль, поставь галочку **Auto Confirm User**.
4. Запрети чужие регистрации: **Authentication → Sign In / Providers** (или Settings) → выключи **Allow new users to sign up**.
5. Скопируй ключи: **Project Settings → API** (Data API / API Keys): **Project URL** и ключ **anon public** (или **publishable**).

### 2. Заполни config.js
Открой `config.js` и вставь туда Project URL и ключ вместо текста «ВСТАВЬ_СЮДА…». Кавычки оставь.

### 3. Выложи на GitHub Pages
1. На GitHub нажми **New repository**, название например `budget`, **Public**, создай.
2. **Add file → Upload files**: перетащи `index.html`, `config.js`, `setup.sql`, `README.md` → **Commit changes**.
3. **Settings → Pages**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/budget/`. Открой его и войди почтой и паролем из шага 1.3.

На телефоне открой тот же адрес и добавь на экран «Домой»: он будет открываться как приложение.

## Безопасность
- Код страницы на бесплатном GitHub публичный, но в нём нет твоих данных. Ключ anon/publishable создан для открытого использования, доступ к данным защищают правила из `setup.sql`: без входа по твоему паролю строки не видны.
- Никогда не вставляй в `config.js` ключ **service_role** / **secret**.
- Раз в пару месяцев делай резервную копию: «План» → «Скачать копию данных».

## Как обновлять сервис
Замени `index.html` в репозитории новой версией (Add file → Upload files). Данные в Supabase при этом не трогаются.
